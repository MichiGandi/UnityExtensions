## Installation

This repo hosts multiple independent Unity packages. Add them via the Unity Package Manager using **Add package from git URL...**:

- **Extensions** (extension methods for Vector, LayerMask, Array, ...)
  ```
  https://github.com/MichiGandi/UnityExtensions.git?path=/Extensions
  ```
- **Singleton Templates** (singleton base classes for MonoBehaviours and prefabs)
  ```
  https://github.com/MichiGandi/UnityExtensions.git?path=/SingeltonTemplates
  ```

To pin a specific version/commit, append `#<tag-or-commit>` to the URL.
